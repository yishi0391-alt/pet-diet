# PetDiet · 宠物养成与日常记录

移动端优先的原生 Web 个人项目，将虚拟宠物成长、金币奖励与饮食、饮水、运动记录结合。当前为前端原型，适合展示交互设计、浏览器 API 与本地状态管理。

## 功能

- 猫、狗、兔宠物选择，成长、对话、走动动画与新手引导。
- 金币商城、房间家具、成就与连续打卡。
- 内置食物检索、按克数记录营养、自定义食物与饮水记录。
- 运动计时、实验性运动传感器计步与 GPS 跑步距离。
- 个人档案、体重记录、周报与 LocalStorage 持久化。

## 技术与结构

HTML5 / CSS3 / 原生 JavaScript；Geolocation、DeviceMotion、LocalStorage。无需构建工具或后端。

- index.html：保留现有页面功能，修正距离单位的当前版本。
- archive/README.original.md：原始 README，含旧版 HTML。
- archive/README.legacy.html：从旧 README 完整提取的历史页面，仅供追溯。
- archive/index.original.html：整理前的现有页面。
- tests/regression.cjs：距离与运动记录回归测试。
- REVIEW.md：比较结果、限制与部署计划。

## 本地运行

直接用浏览器打开 index.html 可体验基础功能；建议通过本地静态服务访问，以获得稳定的存储来源。若已安装 Python，可在项目目录运行 python -m http.server 8000，再访问 http://localhost:8000。定位和运动传感器需要受支持的浏览器、安全上下文及用户授权，必须另做手机实测。

## 验证

安装 Node.js 后运行 node tests/regression.cjs。测试使用模拟浏览器环境验证实际页面函数，不代表手机传感器或页面视觉验收。

## 数据与限制

数据仅保存在当前浏览器，清理站点数据会丢失记录，无账号同步。旧版拍照随机热量功能已在现有页面移除，不提供 AI 食物识别。内置食物营养值与运动消耗是估算，未接入权威营养数据库。计步按每步 0.7 米估算；GPS 内部使用米，界面显示公里。其他运动主要按时间估算消耗，并非自动识别动作。
